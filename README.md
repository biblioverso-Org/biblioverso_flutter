## 📖 Descripción del Proyecto

**Biblioverso** es una aplicación móvil moderna desarrollada en Flutter que revoluciona la gestión bibliotecaria. Ofrece una experiencia fluida e intuitiva para usuarios cliente , facilitando la búsqueda, reserva de libros.

### ✨ Características Principales

- 🔐 **Autenticación Segura**: Sistema completo de registro e inicio de sesión con JWT
- 📚 **Catálogo Digital**: Exploración de libros con búsqueda avanzada y filtros
- ⭐ **Favoritos**: Marca y guarda tus libros preferidos con sincronización en la nube
- 🔔 **Notificaciones**: Alertas en tiempo real sobre reservas y disponibilidad
- 👤 **Gestión de Perfil**: Actualización de datos personales y avatar
- 🏷️ **Categorías**: Organización por género, autor y temática
- 📖 **Detalles Completos**: Información detallada de cada libro con reseñas
- 🎫 **Sistema de Reservas**: Reserva libros fácilmente con confirmación instantánea
- 🔍 **Búsqueda Inteligente**: Busca por título, autor, ISBN o categoría
- 💡 **Recomendaciones**: Sistema de sugerencias basado en preferencias
